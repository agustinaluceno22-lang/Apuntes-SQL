1. Variables
Las variables se dividen principalmente en cualitativas y cuantitativas.

🟣 Variables cualitativas

Representan características o categorías, no cantidades numéricas.

Nominal

Representa un atributo categórico.
No tiene un orden.
Ejemplos: rojo, blanco, azul.

Ordinal

Representa un atributo categórico.
Tiene un orden implícito.
Ejemplo: talle XS → S → M → L → XL.

Binaria

Solo puede tener dos valores posibles.
Ejemplo: sí / no.

👉 Para acordarte:

Nominal = nombres/categorías
Ordinal = categorías con orden
Binaria = 2 opciones

2. Variables cuantitativas

Son variables que representan valores numéricos.

🔵 Continua

Puede tomar cualquier valor dentro de un intervalo.

Ejemplos:

Peso
Altura
Monto
🔵 Discreta

Solo admite determinados valores.

Ejemplos:

Cantidad de hijos
Cantidad de autos
Familia
Ancho de banda

👉 Para acordarte:

Continua = puede tener cualquier valor
Discreta = valores determinados

📊 3. Medidas de posición central

Sirven para representar o resumir los valores centrales de un conjunto de datos.

Media o promedio

Se obtiene:

Suma de todos los valores ÷ cantidad de valores

Ejemplo:
2 + 4 + 6 = 12
12 ÷ 3 = 4

Mediana

Es el valor central de un conjunto de datos ordenados.

Moda

Es el valor que más se repite.

👉 Media = promedio
👉 Mediana = centro
👉 Moda = más repetido

📏 4. Medidas de dispersión

Indican qué tan dispersos o separados están los datos.

Rango

Es la diferencia entre:

Valor máximo − valor mínimo

Varianza

Mide la dispersión de los datos de una muestra respecto a la media.

Si todos los datos son iguales → varianza = 0.

Desviación estándar

Mide el promedio de las desviaciones de los datos respecto al promedio.

Es la raíz cuadrada de la varianza.

👉 Para memorizar:

Rango = máximo − mínimo
Varianza = dispersión
Desviación estándar = √varianza

📐 5. Medidas de posición no central
Cuartiles

Son 3 valores que dividen una serie ordenada de datos en 4 partes iguales.

Q₁ = primer cuartil
Q₂ = segundo cuartil = mediana
Q₃ = tercer cuartil

Cada parte representa el 25% de los datos.

Percentiles

Son 99 puntos que dividen una serie ordenada en 100 partes iguales.

El percentil 50 = mediana.

👉 Cuartiles → 4 partes
👉 Percentiles → 100 partes

🔢 6. Medidas de frecuencia
Frecuencia absoluta

Es la cantidad de veces que aparece un valor en un conjunto de datos.

Ejemplo: si el número 5 aparece 8 veces → frecuencia absoluta = 8.

Frecuencia absoluta acumulada

Es la suma de las frecuencias absolutas anteriores y la actual.

Frecuencia relativa

Es la proporción de valores dentro del conjunto.

Frecuencia relativa acumulada

Es la suma de las frecuencias relativas ordenadas. También puede obtenerse como:

Frecuencia absoluta acumulada ÷ total de casos.
