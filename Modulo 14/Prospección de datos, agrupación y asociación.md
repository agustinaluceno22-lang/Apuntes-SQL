1. Prospección de datos
La prospección de datos busca describir y obtener información significativa a partir de grandes conjuntos de datos, examinando las propiedades de los datos almacenados en grandes bases de datos.

Utiliza principalmente:

Estadística clásica.
Procesamiento informático.
Acciones principales

Durante la prospección se pueden realizar:

Definir distintos tipos de aproximación a los datos.
Plantear hipótesis.
Realizar análisis predictivos.
Realizar muestreos y pruebas estadísticas.
Generar métricas.
Analizar outliers o valores atípicos.
Interpretar resultados según las hipótesis.
Identificar interrupciones.
Elegir medidas de resumen adecuadas.
Buscar relaciones entre los datos.
Analizar subgrupos importantes.
Observar la proporción de valores faltantes.
2. Agrupación

La agrupación o análisis de conglomerados consiste en agrupar objetos que comparten características similares dentro de un conjunto de datos.

📌 Ejemplo:

En una tienda podemos agrupar productos similares, como:

Pan blanco.
Pan integral.

La idea es formar grupos significativos basándose en similitudes.

Aplicaciones

Marketing

Segmentación de clientes.
Análisis de ventas.

Operaciones de negocio

Optimización de procesos.
Gestión de inventario.
Logística.

Observación de la Tierra y procesamiento de imágenes

Clasificación de cobertura terrestre.
Monitoreo de desastres.
Estudios ambientales.
3. Asociación

La Association Rule Mining (ARM), o minería de reglas de asociación, busca descubrir relaciones interesantes entre variables o elementos dentro de grandes bases de datos.

Se basa principalmente en analizar ocurrencias.

📌 Ejemplo clásico:

Analizar qué productos suelen aparecer juntos en un carrito de compras.

Por ejemplo:

Personas que compran pan → también podrían comprar manteca.

Aplicaciones

🛒 Análisis del carrito de compras

Detectar productos que suelen comprarse juntos.

🎯 Sistemas de recomendación

Recomendar productos, películas o contenidos relacionados según el comportamiento del usuario.

🚨 Detección de fraude

Encontrar patrones inusuales o comportamientos sospechosos.

🌐 Uso de la web

Analizar patrones de navegación.
Detectar secuencias comunes de visitas a páginas.

🏥 Cuidado de la salud

Encontrar asociaciones entre síntomas y enfermedades.
4. Diferencia entre agrupación y asociación
Agrupación	Asociación
Forma grupos de datos similares	Busca relaciones entre datos
Se centra en puntos de datos	Se centra en atributos y ocurrencias
Busca similitudes	Busca asociaciones
Ej: segmentar clientes	Ej: productos comprados juntos

📌 Para memorizar:

Agrupación = "¿Qué cosas son parecidas?"

Asociación = "¿Qué cosas aparecen relacionadas?"

Ambas ayudan a descubrir patrones y conocimientos en los datos, pero tienen objetivos diferentes y una no mejora necesariamente a la otra.

🧠 Resumen ultra corto

Prospección: sacar información útil de grandes cantidades de datos.

Agrupación: juntar elementos similares.

Asociación: encontrar elementos que aparecen relacionados.

Outlier: valor atípico.

ARM: minería de reglas de asociación.

Ejemplo de agrupación: segmentar clientes.

Ejemplo de asociación: detectar qué productos se compran juntos.
